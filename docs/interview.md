## 常见追问

**为什么不把全部记录随机打散？**

同一参数组合有多次重复，如果跨训练、测试分区，测试样本的参数组合已经被模型见过。按完整场景划分，才是在检查对新组合的预测能力。

**线性、二次和三次模型有什么区别？**

线性模型只能表达线性关系，多项式增加非线性和参数交叉项。次数越高不一定越好：该演示的应力模型选中二次，而不是三次。选择依据来自训练场景内的交叉验证。

**Ridge 起什么作用？**

多项式特征较多时，系数可能不稳定。Ridge 在拟合误差外加入系数惩罚，减轻过拟合；截距不惩罚。正则化强度在训练数据内比较。

**90% 区间代表每次结果有 90% 概率落在里面吗？**

不能这样简单表述。这里给出对新场景、带随机波动响应的预测区间，校准关注边际覆盖，不保证每个具体参数位置都达到同样覆盖率。测试中的 91% 或 92.33% 是本次合成样本的经验结果。

**为什么 95% 区间的覆盖率这么高？**

校准组只有 20 个，有限样本修正使区间更保守。覆盖率高的同时区间也更宽，所以不能只拿覆盖率宣传准确。

**是不是训练集 R² 很高就可以？**

训练结果可能过拟合。这里先用交叉验证选择，再对单独测试场景报告结果；还区分场景均值与单次实现的误差。

**与汽车行业有什么联系？**

已有有限元建模、工况计算和报告经验，可以支撑分析类任务的学习。这个作品集展示参数输入、响应预测、结果检查的通用流程。真实零部件分析还要补充对应载荷、边界条件、材料和行业验证要求，不能把当前岩土或合成项目称为已经完成的汽车仿真项目。

## 现场演示顺序

1. 打开 README 中的结果图，用半分钟说出输入、输出和数据来源。
2. 打开 `examples/prediction_inputs.csv`，执行 README 的预测命令。
3. 查看输出均值与区间；增大荷载倍率再预测。
4. 将刚度倍率改为 2，演示超域输入被拒绝。
5. 打开 `tests/test_core.py`，解释测试标签变动不影响模型的检查。
